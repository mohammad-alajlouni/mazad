# Development sample assets

`demo-assets.xlsx` contains three fictional inventory rows, including Arabic text. These are test inputs, not client data. Headers are on row 1; each following row is one item. All sheets are read.

`demo-generator.jpg`: “Montreal power backup”, Jean-Daniel Drapeau-Mc Nicoll; brightness/color revision by Soerfm. Source: https://commons.wikimedia.org/wiki/File:Montreal_power_backup.jpg. Used under CC BY-SA 3.0: https://creativecommons.org/licenses/by-sa/3.0/. The downloaded source is unchanged; the application resizes and re-encodes uploads. The photograph illustrates the image pipeline; it does not depict the fictional sample assets or verify their specifications. Preserve attribution in any distributed demo documents containing it.

To link an Excel item to a previously uploaded image, add an `Image` column with that image's ID (displayed on the Images tab). Only images already associated with the same project are resolved. External image URLs are retained as metadata but never fetched by the server.

Replace these assets with client-approved data, images and designs before production use.
