# مسار إعداد كتيّب المزاد والحسابات

العربية واتجاه RTL هما الافتراضي للزائر الجديد. اختيار الإنجليزية صراحة يُحفظ ولا يُلغى عند إعادة فتح الموقع.

## حساب مدير النظام

بعد تسجيل الدخول يصل المدير إلى إدارة الحسابات. ينشئ حساب مستخدم بالبريد وكلمة مرور (12 حرفًا على الأقل)، ويسلّمها للمستخدم خارج الموقع. لا يرسل النظام بريد دعوة ولا يتيح تسجيلًا عامًا. يستطيع المدير تفعيل أو إيقاف حساب المستخدم؛ الإيقاف يلغي جلساته السابقة ولا يحذف مشاريعه.

إدارة الحسابات وتعديل هوية النظام متاحان للأدمن فقط، ويُفرض ذلك في الـAPI. يستطيع المدير استخدام مساحة كتيّباته الشخصية للتجربة، لكنها منفصلة عن إدارة النظام. لا تمنحه صلاحية الإدارة الاطلاع على كتيّبات المستخدمين الخاصة.

## حساب مُعدّ الكتيّبات

توجد صفحة دخول واحدة؛ يحدد النظام الصلاحيات من الحساب، ولا يختار المستخدم أنه أدمن. يرى مُعدّ الكتيّبات مزاداته ومخرجاته فقط، ولا تظهر له إدارة المستخدمين أو إعدادات النظام.

1. **إنشاء كتيّب مزاد:** اسم المزاد، المرجع وبياناته العامة. يبدأ الكتيّب بالعربية وبقالب غلاف افتراضي قابل للتغيير.
2. **المزاد والغلاف:** نوع المزاد (حضوري، إلكتروني، هجين)، الترخيص والجهة المشرفة، التواريخ والأوقات، مكان الحضور والمنصة الإلكترونية، الروابط والنصوص النظامية واختيار الغلاف. حفظ الخطوة ينقل إلى وكيل البيع.
3. **وكيل البيع:** الاسم والوصف والهاتف وواتساب والموقع والحسابات الاجتماعية. يمكن رفع الشعار مباشرة هنا. حفظ الخطوة ينقل إلى العقارات.
4. **العقارات:** إدخال يدوي أو استيراد Excel مع معاينة وربط أعمدة والتحقق قبل الاستيراد. يشمل كل عقار النوع والمدينة والحي والمساحة والصك والمخطط والقطعة ومبلغ المشاركة والمزايا والحدود والروابط والمعلومات الإضافية وعقود الإيجار. يمكن ترتيب العقارات وتعديلها.
5. **الصور والمرفقات:** رفع الصور وربطها بالعقار وتصنيف الرئيسية والإضافية وصورة الغلاف والشعارات. روابط المسح والموقع والمستندات تضاف ضمن بيانات العقار؛ رفع الملفات المباشر هنا مخصص للصور.
6. **المراجعة والتوليد:** عرض بيانات المزاد والوكيل وملخص العقارات. النواقص المطلوبة تمنع توليد الكتيّب، مع أزرار للعودة إلى الخطوة المناسبة. تنبيهات البيانات الاختيارية لا تمنع التوليد. الزر الأساسي يولّد كتيّب المزاد وحده.
7. **المعاينة والتنزيل:** بعد التوليد تُفتح مسودة الكتيّب مباشرة. مراجعة الصفحات، اعتماد الكتيّب، ثم تنزيل PDF. تغيير البيانات يجعل النسخة بحاجة لإعادة التوليد قبل اعتمادها مجددًا.

شريط العمل داخل المزاد يحوي ست خطوات (بدءًا من المزاد والغلاف). البيانات محفوظة بعد الضغط على أزرار الحفظ، مع تنبيه عند مغادرة نموذج غير محفوظ داخل الخطوات. إعادة فتح المزاد تُوجّه إلى البيانات الناقصة أو مخرجات الكتيّب إن وجدت.

المخرجات السبعة الأخرى متاحة ضمن «أدوات ومخرجات إضافية». لا تُنتج تلقائيًا أثناء إنشاء الكتيّب. تبقى المخرجات القديمة قابلة للوصول من قائمة المخرجات.

## التحقق

اختبارات الـAPI تغطي إنشاء الحساب، منع تصعيد الصلاحيات، منع تعديل الإعدادات للمستخدم، عزل المشاريع والملفات، توليد واعتماد وتنزيل كتيّب بحساب مستخدم، وإيقاف الحساب وإلغاء جلساته. اختبارات المتصفح تغطي الفلو اليدوي وExcel والعربية الافتراضية وحساب المستخدم والجوال والمخرجات الإضافية بالعربية والإنجليزية.
