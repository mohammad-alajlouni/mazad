# أنواع المزادات والتحقق عند الإدخال

تستخدم الواجهة عقد الحقول الذي يعيده API ضمن workflow في تفاصيل المشروع، وتستخدم جاهزية البيانات المحفوظة لمنع تجاوز الخطوات الناقصة.

| النوع | الموعد | مكان المشاركة | المخرجات |
| --- | --- | --- | --- |
| حضوري | تاريخ المزاد ووقت البداية، ووقت نهاية اختياري | موقع الحضور | تاريخ واحد وموقع الحضور؛ شروط الحضوري؛ لا تظهر منصة أو خطوات تسجيل إلكتروني |
| إلكتروني | تاريخ ووقت البداية والنهاية | اسم المنصة ورابطها للكتيّب والمشروع المتكامل | فترة المزايدة والمنصة، شروط الإلكتروني وخطوات المشاركة الإلكترونية؛ لا يظهر موقع حضور |
| هجين | تاريخ ووقت البداية والنهاية | المنصة وموقع الحضور معًا | الطريقتان في بيانات المزاد، شروط الهجين وخطوات المشاركة الإلكترونية |

المرجع: دليل التسويق والهوية V2، صفحة 13 لمعلومات الأنواع، وصفحات الشروط والمشاركة 23–26. تظل مقاسات الكتيّب والبنرات والمنشورات والقوالب المعتمدة كما هي.

عند تغيير النوع تُزال الحقول غير المناسبة من البيانات المحفوظة. يُطبَّق التنظيف أيضًا عند بناء نسخة التوليد من المشاريع القديمة؛ فلا يتسرّب موقع حضوري أو رابط منصة أو تاريخ قديم إلى صفحات الغلاف والتواصل ورموز QR.

## التحقق المبكر

- تظهر علامة النجمة والرسائل بجانب الحقول المطلوبة؛ تتغير قائمة المطلوب حسب النوع ونطاق المشروع.
- يُمنع حفظ النموذج الناقص والانتقال عبر «التالي» أو النقر المباشر على خطوة لاحقة أو قسم إنتاج آخر.
- يجب حفظ البيانات المكتملة قبل المتابعة. الرجوع لخطوة سابقة ومراجعة المخرجات التاريخية يظل ممكنًا.
- العقارات المستوردة من الإكسل تُفحص في مرحلة العقارات أيضًا، فلا يُسمح بتجاوز النواقص بمجرد إتمام الاستيراد.
- المشروع المتكامل يتطلب شعار الوكيل وشعار المزاد وصورة عامة وصورة رئيسية لكل عقار، لتُستخدم دون رفعها مجددًا في أي نوع منشور.
- الحملات المستقلة تطلب ما يلزم لمخرجاتها؛ صور الكتيّب المستقل الاختيارية تبقى تحذيرًا، ولا تتحول جميع الحقول الاختيارية إلى إلزامية.
- التحقق على السيرفر عند التوليد والفحص الهندسي يظلان قائمين بجانب التحقق المبكر.

الاختبارات تغطي الأنواع الثلاثة في المخرجات الثلاثة، تنظيف بيانات الأنواع السابقة، توافق المطلوب مع الحقول الظاهرة، ومنع تجاوز متطلبات المزاد والوكيل والعقار من واجهة المتصفح.
