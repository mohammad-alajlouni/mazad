# API guide

Interactive schemas are generated by FastAPI at `/docs`; machine-readable OpenAPI is at `/openapi.json`. Business routes are prefixed `/api`. Authentication uses the `session` cookie. JSON mutations use `Content-Type: application/json`; files use multipart form data. Browser origins must match `CORS_ORIGINS`.

| Method | Endpoint | Operation |
|---|---|---|
| GET | `/api/health` | Check API and database connectivity |
| POST | `/api/auth/login` | `{email,password}`; sets HttpOnly cookie |
| GET | `/api/auth/me` | Authenticated administrator email |
| POST | `/api/auth/logout` | Clear cookie and revoke administrator sessions |
| GET | `/api/dashboard` | Live project/output counts and audit activity |
| GET, POST | `/api/projects` | List/create projects |
| GET, PUT | `/api/projects/{id}` | View/edit project metadata, including status |
| POST | `/api/projects/{id}/items` | Create normalized item |
| PUT, DELETE | `/api/projects/{id}/items/{item_id}` | Edit/delete an item in that project |
| POST | `/api/projects/{id}/images` | Multipart `file`, optional `item_id` |
| GET | `/api/images/{id}` | Private uploaded-image bytes |
| GET | `/api/excel-mapping` | Default Excel header aliases |
| POST | `/api/projects/{id}/imports/preview` | Multipart workbook `file`, optional JSON string `mapping` |
| POST | `/api/projects/{id}/imports/{import_id}/commit` | Import valid preview rows once |
| GET | `/api/output-types` | Generator registry keys and labels |
| POST | `/api/projects/{id}/generate` | `{types?: [...], use_ai?: false}`; returns generated drafts |
| GET | `/api/outputs` | All output summaries and current file IDs |
| GET, PUT | `/api/outputs/{id}` | Retrieve output / save `{review_text}` as Draft |
| POST | `/api/outputs/{id}/approve` | Verify revision, approve, re-render |
| POST | `/api/outputs/{id}/regenerate` | Replace with current source snapshot; return to Draft |
| GET | `/api/files/{id}` | Private preview bytes |
| GET | `/api/files/{id}?download=true` | Approved final export |
| GET, PUT | `/api/settings` | Read safe configuration / save branding |
| POST | `/api/settings/logo` | Validated logo upload |
| POST | `/api/projects/{id}/ai` | `{purpose: summary|description|social_content|analysis}`; returns stored draft or availability error |

Project input: `name`, `code`, optional `customer`, `description`, `date`, `location`, `notes`, `status` (`DRAFT`, `ACTIVE`, `COMPLETED`). Item input: `title`, `reference`, `category`, `description`, `specifications`, `quantity`, `financial_value`, `technical_information`, `notes`, `attributes` object. Financial value is **per unit**. Quantity defaults to one; value defaults to zero. Missing nonfinancial text is preserved as missing, not invented.

Example custom Excel mapping:

```json
{"Asset name":"title","Asset ID":"reference","Count":"quantity","Unit price":"financial_value","Photo ID":"image_reference"}
```

Preview response contains an import ID, valid/invalid counts, and rows with `sheet`, `row_number`, normalized `data` and `errors`. Preview does not create items. Commit returns `{imported, skipped}`. Replay returns 409.

Output keys: `asset_study`, `project_booklet`, `banners`, `regulatory_form`, `closing_form`, `social_content`, `final_output_report`, `booklet_study_report`.

Errors use `{detail: "human-readable message"}`; validation errors use FastAPI's standard list with field locations. Status codes include 400 invalid workbook/image/mapping, 401 unauthenticated, 403 invalid browser origin, 404 missing/project-mismatched record, 409 duplicate reference/stale output/replayed import/unapproved export, 413 upload too large, 422 schema validation and 429 login throttling. Unexpected errors return a generic 500 message, without stack traces.

AI provider errors use a successful structured result (`ERROR` or `UNAVAILABLE`) so callers can continue with deterministic output. Generated text is never automatically approved. Direct AI results are persisted; use the output review endpoint to incorporate and review that text in a deliverable.
